# Snake
Console Snake Game version 2.0<br>
Created by me from OOP Workshop of SoftUni.<br> 
Structured game with Core, GameObjects, Intefaces, Enums and Utilities.<br><br>

# Points:<br>
- symbol '*' gives 1 point<br>
- symbol '$' gives 2 points<br>
- symbol '#' gives 3 points<br><br>

When you touch the walls of the field it is game over. You can restart by pressing 'Y'.<br><br>
